# Prompt 模板库

本目录保存了开发过程中实际使用的 Prompt 模板，覆盖从项目初始化到支付集成的全流程。

| # | 文件 | 对应阶段 | 使用天数 |
|---|------|---------|:--:|
| 01 | init-project | 脚手架 + 架构设计 | 1-2 天 |
| 02 | generate-three-layer | 标准 CRUD 代码生成（复用于多数模块） | 全程 |
| 03 | user-auth | 登录认证（验证码 + JWT + 拦截器） | 4-6 天 |
| 04 | shopping-cart | Redis Hash 购物车 | 7-8 天 |
| 05 | order-submit | 订单 + 乐观锁防超卖 | 9-12 天 |
| 06 | wechat-pay | 微信支付 V3 + 回调幂等 | 16-18 天 |
| 07 | rbac-admin | 后台管理 + RBAC 权限 | 19-22 天 |

## 复用效果

- `02-generate-three-layer` 模板复用于菜品、套餐、分类、员工、地址簿等 6 个模块
- 同类模块开发效率提升约 60%（从半天/模块 → 约 40 分钟/模块）

## 使用方式

每个 Prompt 在 Claude Code 中使用 `/prompt` 加载后，根据具体表名和业务逻辑微调参数。生成后经人工 Review（重点检查事务边界、异常处理、并发安全），修正 2-3 轮后进入集成测试。
